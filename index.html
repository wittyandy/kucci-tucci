Using Copilot Free

  1. Install VS Code and sign in with an adult-managed GitHub account.
  2. Open Copilot Chat and choose Agent mode when available.
  3. Open the parent project folder.
  4. Paste one version prompt and review its changes.
  5. Test before asking for the next version.
Free plans have usage limits. Work on one version at a time. Keep prompts short, test carefully, and wait for the limit to reset instead of paying. The tutorial never requires a paid feature.

Add three new chairs and clearly different small, medium, and large rugs. Keep the center window at 80 percent of its earlier width and height. Increase their latest width by another 10 percent and height by another 20 percent: use 647 by 377 pixels for the fabric curtains and 484 by 306 pixels for the Roman blind on desktop, with proportional mobile sizes. Use the approved Kucci and Tucci designs. Kucci has a short brown bob, mint cardigan, white T-shirt, coral skirt, socks, and mint sneakers. Tucci has two brown hair buns with flowers, a yellow T-shirt, purple overalls, striped socks, and purple sneakers. Create genuine Front, West, and East illustrations for Kucci, Tucci, and every animal. Direction buttons must load those separate files; never rotate one image. Hide free clockwise and counter-clockwise rotation for people and animals. Reduce both current human starting sizes by another 5 percent, making Kucci's scale 1.37275 and Tucci's scale 2.4225. Add hidden Easter-egg pets named Scottie and Emi. Their catalog cards and icon containers must be exactly the same size as every other catalog item. Inside each standard icon, enlarge only the readable purple animal silhouette and its light question mark while keeping the whole silhouette visible. Build Scottie's mystery icon from the East- or West-facing side-profile shape rather than the Front-facing shape. Placing one reveals the pet. Scottie is a solid, fully opaque all-white Scottish Terrier stuffed animal with subtle cream-gray fur shading. Compared with the prior Scottie artwork, shorten the legs by 40 percent and make the front-facing legs 20 percent thicker and the East- and West-facing legs 10 percent thicker. Keep Scottie's starting scale at 2.1. Emi is a friendly, solid all-white fluffy Sheepadoodle stuffed animal whose eyes are partly covered by fur. Horizontal and vertical resizing may stretch independently. Corner dragging must preserve the object's width-to-height proportion. Scan the alpha channel of the exact image element currently displayed on screen instead of loading a second copy or measuring an embedded Snapshot asset. Ignore alpha values below 16, add about 1.5 percent safety padding, and use the displayed image's natural dimensions and object-fit scale to position the white dotted rectangle. Kucci, Tucci, animals, books, toys, plants, rugs, posters, lamps, curtains, blinds, and room walls must not have color controls. Reusable “make my object” prompt
I want to add an original object to my room game. It is a [OBJECT] named [NAME]. It belongs in the [CATEGORY] category. It should look [SHAPE AND DETAILS] and use [COLORS]. Please create a complete transparent-background PNG or WebP image. Make the whole object fit inside the image with a little empty space around every edge. Do not copy an existing brand or character. Add it to the object list in game.js with a room size that makes sense compared with the other objects. If direction matters, make three separate images: a perfectly straight Front view, an inward-facing West view, and an inward-facing East view. Use about 80 degrees for sofas and chairs, about 30 degrees for beds, and about 55 to 60 degrees for rectangular tables and desks. Do not fake the side views by rotating the front image with CSS. Keep every existing object and feature working. Tell me the new file names and three things to test.

Invent your own characters

Choose a name, age, hair color, clothing colors, personality, and three favorite activities. Keep the color controls simple and avoid using private information about a real child.

Give objects actions

Try “the lamp glows when clicked,” “the cat curls up on a rug,” or “the toy box opens and closes.” Add one action, test it, then add another.

The one-change ruleAdd one object or action, save, refresh, and test. If it works, keep it. If it breaks, return to the last version or use the repair prompt below.

Explain what you saw

Problem-solving prompt
I am making a room-decorating browser game. When I [SAY WHAT YOU DID], the game [SAY WHAT HAPPENED]. I expected [SAY WHAT SHOULD HAPPEN]. Here are my current files. Find the cause, keep every working feature, and give me the complete corrected file or files. Explain the problem in one short sentence and give me three quick tests. Share it for free

Publish with GitHub Pages

An adult should handle the GitHub account and public posting. Do not publish a child's full name, photo, school, address, or other private information.

  1. Create the repository. On GitHub, create a public repository named kucci-tucci.
  2. Upload this package. Unzip it and upload everything inside. Keep this landing-page index.html at the top level.
  3. Turn on Pages. Open Settings → Pages, choose Deploy from a branch, then choose main and /(root).
  4. Visit the site. The address will usually be https://YOUR-USERNAME.github.io/kucci-tucci/.
If Copilot helps with Git: ask it to check whether Git user name and email are configured before the first commit. Do not paste passwords or access tokens into AI chat. The GitHub website upload method above does not require terminal commands.
